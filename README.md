# 🐟 Peixe come Minhoca

Um jogo simples e divertido desenvolvido do zero utilizando **C++** e **OpenGL**. 

Você controla um peixinho com um único objetivo na vida: nadar no mar sem esbarrar em nada e devorar o máximo de minhocas que conseguir! 🪱

## 🎮 Como Jogar
* **Movimentação:** Use as setas do teclado (ou W, A, S, D) para nadar.
* **Objetivo:** Coma as minhocas para ganhar pontos e evite sair da tela!

## 🛠️ Tecnologias Utilizadas
* **C++** (Lógica do jogo)
* **OpenGL** (Renderização gráfica)
